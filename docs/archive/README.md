# Архив

Содержимое этой папки не участвует в сборке и не описывает текущую задачу.

- `fastapi-prototype/` — серверный прототип Фазы 0. Рабочий бэкенд реализован
  через Next.js API Routes и Prisma в `frontend/`;
- `tasks/` — завершённые или устаревшие задания для отдельных агентов.

Не используйте архив как источник актуальных требований.
