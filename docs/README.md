# Документы проекта

Здесь лежат материалы, которые не нужно читать при каждом запуске агента.

- `plans/` — завершённые планы реализации;
- `qa/` — отчёты, сравнения и скриншоты проверок;
- `archive/` — старый код и задания, сохранённые только для истории.

Текущие правила и состояние работы находятся в корне репозитория: начинать нужно
с `AGENTS.md`, затем открывать только указанные там документы.
