# Дизайн-система «Методики»

Как всё устроено и как править. Код системы — в `frontend/src/app/globals.css`,
раздел «ДИЗАЙН-СИСТЕМА».

---

## 1. Цвет: от тона раздела пляшет всё

У каждого раздела свой тон. Он задаётся **один раз** в `app-shell.tsx`
атрибутом `data-accent`, дальше все блоки берут его автоматически.

| Раздел | Тон |
|---|---|
| Главная | янтарь |
| Сессии | олива |
| Клиенты, Терапия | лаванда |
| Инструменты | персик |
| Кабинет | янтарь |

Из тона получаются три градации — и больше ничего придумывать не надо:

| Переменная | Что это | Где применяется |
|---|---|---|
| `--head-soft` | **лёгкий** | заливка блоков, заливка статусов |
| `--head` | **базовый** | крупные акцентные плашки |
| `--edge` | **тёмный** | обводки, кнопки, иконки |

Плюс неизменные: `--ink` (чернила, текст), `--muted` (текст светлее),
`--surface` (белый).

**Правило текста на заливке.** Только белый или чернильный — никогда тот же
цвет, что и заливка. На тёмном (`--edge`, `--ink`) — белый. На лёгком
(`--head-soft`, белом) — чернильный.

---

## 2. Пять правил, от которых не отступаем

1. **Теней нет нигде.** Ни у блоков, ни у кнопок. Глубина — заливкой.
2. **Безрамочный блок = цветная заливка.** Белый блок = рамка тоном раздела.
   Белого блока без рамки не бывает.
3. **Блок внутри блока — без рамки.** Вложенность показывается заливкой.
4. **Статусы и иконки — без рамок.**
5. **Заголовки — чернила, текст — чернила посветлее** (`--muted`).

Правила 1–4 включены глобально в `globals.css` и действуют на весь проект,
включая инлайновые стили. Отключить для конкретного элемента — класс
`.keep-style`.

## 3. Готовые классы

Собирайте экраны из них, а не инлайном.

### Блоки

```jsx
<div className="card">…</div>        {/* белый + рамка тоном раздела */}
<div className="card-soft">…</div>   {/* лёгкая заливка, без рамки */}
<div className="card-nested">…</div> {/* блок внутри блока, без рамки */}
```

### Статусы

```jsx
<span className="chip">В терапии</span>              {/* лёгкий фон, чернила */}
<span className="chip chip-strong">Новое</span>      {/* тёмный фон, белый */}
```

Другой тон, чем у раздела, — только заливкой:
`<span className="chip" style={{ background: "var(--green-soft)" }}>`

### Кнопки

```jsx
<button className="btn">Записаться</button>       {/* тёмный тон, белый текст */}
<button className="btn btn-soft">Позже</button>    {/* лёгкий фон, чернила */}
<button className="btn btn-white">В каталог</button> {/* белая, обводка тоном */}
<button className="btn btn-ink">Оплатить</button>  {/* чернила, белый текст */}
```

`btn-white` — для кнопки **внутри** `card-soft`: там `btn-soft` сливается с
фоном блока. У всех вариантов обводка есть всегда, даже если кнопка свёрстана
спаном внутри ссылки.

### Иконка

```jsx
<span className="ico h-10 w-10"><Icon name="calendar" /></span>
<span className="ico ico-white h-10 w-10">…</span>  {/* внутри card-soft */}
```

### Стрелка «дальше»

Одна на весь проект. Не рисуйте свою — импортируйте:

```jsx
import { Arrow } from "@/components/blocks";
<Arrow />
```

Вид меняется в `.arrow` в `globals.css` — сразу везде. Раскрывающиеся
шевроны — тот же `.arrow` плюс поворот на 90°.

## 4. Шрифты

Две гарнитуры, семь ступеней. Размеры взяты по фактическим пикам в коде,
а не выдуманы.

| Класс | Размер | Для чего |
|---|---|---|
| `.t-display` | 24 | заголовок экрана |
| `.t-title` | 20 | заголовок блока |
| `.t-head` | 16 | заголовок карточки, имя |
| `.t-body` | 14 | основной текст |
| `.t-sub` | 13 | вторичный текст |
| `.t-cap` | 12 | подписи |
| `.t-micro` | 11 | надзаголовки капсом |

Заголовки (`.t-display`, `.t-title`, `.t-head`, теги `h1`–`h3`) — **Nunito**.
Остальное — **Golos Text**.

Новых размеров не заводим. Нужен другой размер — значит, ступень выбрана
неверно.

---

## 5. Как поменять что-то глобально

| Задача | Где править |
|---|---|
| Тон раздела | `[data-accent="…"]` в `globals.css` |
| Какой раздел каким тоном | `accentFor()` в `components/app-shell.tsx` |
| Толщина обводок | `--bw`, `--bw-lg` |
| Скругления | `--r-block`, `--r-sm` |
| Размер шрифта в ступени | `.t-*` в `globals.css` |
| Вид кнопок везде | `.btn` в `globals.css` |
| Вид статусов везде | `.chip` в `globals.css` |
| Вид стрелок везде | `.arrow` в `globals.css` |
| Цвет рамки белых блоков | `--stroke` в `globals.css` (сейчас = `--edge`) |

Одна правка в `globals.css` меняет весь проект — по файлам ходить не нужно.
