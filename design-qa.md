# Design QA — модули «Заметки» и «Задания»

- Source visual truth: изображение из пользовательского сообщения от 1 августа 2026 (мобильный экран с компактными карточками и переходами).
- Implementation screenshot: недоступен — встроенный браузер не подключён в текущей сессии.
- Viewport: целевой мобильный экран приложения; точный размер референса не указан.
- Source pixels: 159 × 282 px в сообщении.
- Implementation pixels / CSS size / density: не зафиксированы из-за отсутствия браузерного снимка.
- State: клиентская терапия и карточка клиента психолога, подключённые заметки, активное/пустое задание.
- Full-view comparison evidence: заблокировано отсутствием браузерного снимка реализации.
- Focused region comparison evidence: заблокировано по той же причине.

**Findings**

- [P2] Визуальное сравнение реализации с референсом не выполнено.
  Location: миниатюры заметок и заданий, четыре подробных экрана.
  Evidence: исходный референс доступен, но встроенный браузер вернул `No browser is available`.
  Impact: нельзя доказательно проверить плотность, переносы текста и вертикальный ритм на реальном мобильном viewport.
  Fix: открыть локальную реализацию во встроенном браузере, снять те же состояния и провести повторное сравнение.
